# VLGO — интерактивный прототип

Мобильный прототип VLGO: необычные места Владивостока «от своих» и общий выбор с друзьями.
Экран рассчитан на телефон (390×844). На компьютере телефон показывается по центру окна, на телефоне — во весь экран, без рамки.

**Онлайн:** https://d0ssh1.github.io/VLGO/ — GitHub Pages отдаёт ветку `main`, корневая страница сама открывает собранный прототип из `dist/`. После изменений: `npm run build` и закоммитить `dist/`.

## Как открыть

- **Без установки.** Откройте `dist/index.html` в браузере. Прототип работает прямо с диска.
- **В режиме разработки.** Нужен Node.js 18+:
  ```
  npm install
  npm run dev      # http://localhost:5173, с телефона в той же сети — по IP компьютера
  npm run build    # собирает dist/
  ```

## Сценарий

1. **Заставка.** Капля краски падает и становится «o» в логотипе, буквы прорисовываются кистью, звезда вращается и встаёт на место.
2. **Интересы.** Один тап — «нравится», второй — «не интересно», третий — сброс.
3. **Лента.** Можно открыть «находку» и карточки мест.
4. **Место.** «В компанию» и «Маршрут».
5. **Компания.** Друзья-капли, план на сегодня, время, бюджет, дорога. Кнопка «Выбирать вместе».
6. **Свайп.** Карточку можно тянуть пальцем или нажимать ★ / ✕ / закладку. После двух «хочу» открывается голосование.
7. **Голосование.** Кнопка «Напомнить»: Даша голосует, и открывается «Сошлись».
8. **Сошлись.** Капли друзей падают в общую лужу с фото места, расходится рябь, появляется слово.
9. **Карта, Избранное, Профиль** — переключаются через таб-бар. Плюс в центре таб-бара собирает компанию.

## Архитектура

```
src/
  main.js            запуск: шрифты → сцена → роутер
  core/
    loop.js          единый requestAnimationFrame-цикл, tween, easing, prefers-reduced-motion
    paint.js         «живая краска»: контуры дышат волнами, текстура переливается
    blob.js          генератор клякс (метаболы + marching squares): у каждой карточки своя клякса, форма перетекает
    router.js        экраны и переходы: flood (заливка краской), push/pop, tab
    stage.js         масштабирование макета 390×844 под любой экран
    dom.js, util.js  мелкие помощники
  ui/                звезда, логотип, огромное слово (подгонка по метрикам шрифта), иконки, кнопки
  screens/           по файлу на экран + art.js (собирает краску, фото, слово, звезду)
  styles/            tokens.css (цвета, шрифты), base, components, motion, screens
  data/
    shapes.json      геометрия краски и окон для фото — экспорт из дизайн-генератора
    content.js       места, друзья, интересы
scripts/
  export_shapes.py   выгрузка геометрии из Python-генератора макетов
  shoot.py           скриншоты собранного прототипа для проверки
public/assets/       фото, текстура гуаши, слой улиц для карты
```

## Анимация и производительность

- **Один цикл анимации.** Краска пересчитывается 30 раз в секунду, а не 60, и только у видимого экрана. В фоновой вкладке цикл засыпает.
- **Движение краски.** Края смещаются по нормали тремя бегущими синусоидами с несоизмеримыми скоростями и медленным «дыханием» амплитуды. Форма не зацикливается заметно и не самопересекается.
- **Текстура.** Переливается двумя слоями: два слоя гуаши дрейфуют навстречу друг другу, сверху проходит блик. Это нативные SVG-анимации, без JS.
- **Без тяжёлых фильтров.** На движущихся формах нет SVG-фильтров. Мокрый край — это внутренний штрих, обрезанный по форме.
- **prefers-reduced-motion.** Если в системе включена эта настройка, краска замирает, а переходы становятся мгновенными.

Шрифты Inter и Inter Tight (OFL) встроены в сборку, на интернет они не зависят.
